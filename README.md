# Phishing Email Detection & Investigation Lab

A hands-on cybersecurity lab for learning phishing email detection,
investigation, IOC extraction, threat intelligence, MITRE ATT&CK mapping,
SOC reporting, and AI-assisted email analysis.

## Project Goals

- Understand phishing from fundamentals to advanced investigation
- Analyze raw email headers and SMTP information
- Investigate SPF, DKIM, and DMARC
- Investigate URLs, domains, DNS, IPs, and attachments
- Extract and correlate IOCs
- Use threat intelligence platforms
- Map phishing activity to MITRE ATT&CK
- Produce SOC-style investigation reports
- Automate repetitive investigation tasks
- Evaluate AI-assisted phishing analysis

## Project Status

Early development.

The project will be built progressively through hands-on
investigation scenarios rather than implementing the entire system at once.

## Investigation Workflow

Email
→ Header Analysis
→ Authentication Analysis
→ Sender Investigation
→ URL/Domain Investigation
→ Attachment Triage
→ Threat Intelligence
→ IOC Correlation
→ MITRE ATT&CK
→ Verdict
→ Response
→ Detection Improvements
→ AI-Assisted Analysis

## Repository Structure

- `docs/` — Project documentation and learning material
- `lab/` — Controlled lab scenarios and evidence
- `investigations/` — SOC investigation cases
- `src/` — Investigation and automation code
- `ai/` — AI-assisted analysis
- `detection/` — Detection engineering content
- `tests/` — Automated tests
